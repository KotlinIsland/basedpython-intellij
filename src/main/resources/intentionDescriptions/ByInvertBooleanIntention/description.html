Gives a boolean the opposite meaning under a name that says so — a variable assigned True or False, a parameter defaulting to one, or a def declared -> bool — and keeps every use meaning what it meant: each read is negated or loses its not, each value it is given is negated, and so is each call of a function, across the project. The new name is not_ before the old one, or the old one without its not_. Refused where a use could not keep its meaning, such as a parameter some call passes by position, or a method whose overrides would have to change with it.
