Reports a print(...) statement in a .by file that a log point could stand in for.

The quick-fix deletes the statement and puts a non-suspending line breakpoint that logs the call's arguments on the statement that followed it, which runs at the moment the print did, so the output still reaches the run console under the debugger without the call being in the file.

A print that is the last statement of its block is not reported, since the line after it runs at some other time.

Example:

print(f"total: {total}")
save(total)

After the quick-fix is applied, the print line is gone and a log point on save(total) logs f"total: {total}".
